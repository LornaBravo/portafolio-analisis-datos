# Planificación y buenas prácticas del portafolio

## Propósito

Este portafolio fue creado para reunir y presentar proyectos de análisis de datos de manera ordenada, accesible y comprensible. Su objetivo es mostrar tanto las habilidades técnicas utilizadas como la capacidad de explicar problemas, decisiones, resultados y aprendizajes.

## Elección del repositorio

Se eligió GitHub porque permite:

- Mantener los proyectos disponibles mediante un enlace público.
- Organizar código, notebooks y documentación en una misma plataforma.
- Registrar los cambios realizados a lo largo del tiempo.
- Presentar los proyectos de una manera conocida dentro de la industria tecnológica.
- Facilitar la revisión del trabajo por parte de docentes, reclutadores y equipos técnicos.
- Enlazar cada proyecto con herramientas externas, como Google Colab o LinkedIn.

## Características del portafolio

El repositorio cuenta con:

- Una presentación personal y una descripción del perfil profesional.
- Enlaces a LinkedIn y GitHub.
- Un índice de proyectos desde el README principal.
- Carpetas independientes para cada proyecto.
- Documentación específica con objetivos, metodología, tecnologías, resultados y conclusiones.
- Acceso al código fuente y a los notebooks ejecutados.
- Una estructura preparada para incorporar nuevos proyectos.

## Buenas prácticas aplicadas

- Uso de nombres de carpetas y archivos claros.
- Separación entre la presentación general y la documentación de cada proyecto.
- README principal como punto de entrada al portafolio.
- README propio para explicar cada trabajo.
- Descripción del problema antes de presentar el código.
- Identificación de tecnologías y herramientas utilizadas.
- Presentación de métricas y resultados verificables.
- Inclusión de conclusiones, limitaciones y mejoras futuras.
- Enlaces funcionales a los proyectos y perfiles profesionales.
- Registro de cambios mediante commits descriptivos.
- Conservación de los resultados de ejecución dentro del notebook.

## Mejoras incorporadas

A partir de la revisión del portafolio se realizaron las siguientes mejoras:

- Se reemplazó la sección de portafolio en construcción por un proyecto real.
- Se agregó una presentación profesional más completa.
- Se incorporó el enlace directo a LinkedIn.
- Se documentó el proyecto de PySpark en una carpeta independiente.
- Se añadieron el objetivo, la metodología, las tecnologías, los resultados y las conclusiones.
- Se incluyeron accesos al notebook publicado en GitHub y a su versión original en Google Colab.
- Se explicitaron las limitaciones del proyecto y sus posibles mejoras.
- Se incorporó este documento con la planificación, razones y buenas prácticas del repositorio.

## Organización futura

Los próximos trabajos se incorporarán manteniendo la misma estructura documental, de modo que cada proyecto pueda revisarse de forma independiente y el README principal funcione como índice general del portafolio.
